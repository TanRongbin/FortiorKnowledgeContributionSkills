# Fortior Knowledge Contribution Skills

Open-source AI skills for capturing engineering experience and contributing structured software review knowledge.

This repository provides reusable contribution skills for multiple local AI coding environments. It separates **Engineering Experience** from **Review Point** knowledge and supports controlled submission to Feishu/Lark Bitable through a gateway or owner-side direct mode.

See `docs/ARCHITECTURE.md` for the knowledge model and `skills/fortior-knowledge-contributor/SKILL.md` for the main skill contract.
